# 苏州信息化招标监控 — 项目介绍

> 本文档概述本部署交接包内的项目及其功能，便于接手同事快速了解全貌。

## 一、项目概述

「苏州信息化招标监控」是一个面向苏州本地政府采购与公共资源交易公告的**自动化采集与展示系统**。它每天定时增量抓取官方平台上的信息化采购公告，按项目编号去重，并在本地网页上集中展示公告正文、表格、联系方式和项目附件，方便团队一站式查阅与跟进。

## 二、核心功能

1. **每日增量采集**：定时抓取官方平台最新公告，自动去重、增量更新。
2. **正文与附件同页查看**：点击项目即可在同一页面阅读完整公告、表格、联系方式与关联公告，保留原网站链接。
3. **附件绑定与预览**：附件按项目隔离保存；PDF、图片、纯文本可在线预览，其他格式下载查看。
4. **多维度筛选**：支持全文、采购范围、预算、采购方式、区域、附件、完整度、跟进状态等筛选。
5. **Excel 导出**：一键导出项目清单、公告详情、附件清单三张表，支持按筛选、勾选或全部留存项目导出。
6. **过期自动清理**：投标/响应截止后保留 30 天，无法识别截止日期的从发布日期起保留 60 天，自动清理。
7. **可视化管理页面**：本机 Web 页面（默认 http://127.0.0.1:8765/），只监听本机地址。
8. **每日定时任务**：默认每天 08:30 自动执行采集、过期清理与备份（Windows 任务计划）。

## 三、系统组成（模块）

| 模块/目录 | 说明 |
|-----------|------|
| `tender_monitor` | 核心 Python 包：抓取、去重、解析、过期规则、导出、Web 服务 |
| `web` | 可视化管理页面（前端资源） |
| `data` | SQLite 数据库、CSV 清单、附件、备份、源页面快照 |
| `tests` | 单元测试 + UI 冒烟测试 |
| `*.ps1` | Windows 脚本：每日定时任务安装/卸载、页面启停 |
| `config.toml` | 运行配置（回溯天数、抓取页数、请求间隔等） |

## 四、数据源

- **苏州市政府采购网**：集中采购与分散采购的货物、服务公告。
- **苏州市公共资源交易平台**：国企采购及其他交易。

## 五、技术栈

- Python 3.11
- SQLite（本地数据库）
- openpyxl（Excel 导出）
- tzdata（时区）

## 六、部署要点（摘要）

- 目标：阿里云服务器，免登录、只读展示。
- 运行：`python -m tender_monitor web`（仅监听 127.0.0.1）。
- 每日任务：`python -m tender_monitor run`。
- 对外开放前需完成只读模式、反向代理、路由白名单等加固（详见包内《00-部署交接说明-先读.md》）。
